## 開設手順は「つまずく所」だけ押さえる

Vultrの画面操作自体は難しくありません。サーバータイプを選び、リージョンを選び、想定人数からプランを決めてConfigureへ進み、Marketplace Appsで`Minecraft (Vanilla)`を検索して選択、Additional Featuresで**Limited Login**（sudo権限を持つ制限ユーザーを作る）にチェックを入れてDeploy Nowです。MinecraftとJavaのインストールは最大10分かかり、ステータスがRunningになってからSSH接続情報を取ります。

問題はこの後にあります。

**25565を開けていない。** VultrのUbuntuイメージはufwが有効で、許可されているのはSSHだけです。Marketplaceアプリがポートを自動で開けるという記述は公式ドキュメントにはなく、自分で開ける必要があります。SSHで入って次を実行します。


sudo ufw allow ssh
sudo ufw allow 25565/tcp
sudo ufw enable
sudo ufw status


「サーバーは動いているのに接続できない」の原因は、まずここです。Vultrの管理画面側でファイアウォールグループを追加した場合も、25565とSSHの両方を許可しないと弾かれます。

**設定ファイルを編集する前に止めていない。** `server.properties`は必ずサーバーを停止してから編集し、終わったら起動し直します。見る項目は`motd`（サーバー一覧に出る文言）、`gamemode`、`difficulty`、`max-players`、`view-distance`（2〜32、負荷に直結）、`online-mode`（`true`で正規アカウント必須）、`white-list`です。`server-ip`は空欄のままにしてください。ここにIPを書くと起動しなくなります。

**メモリを全部JVMに渡している。** Javaの起動オプション`-Xmx`（最大ヒープ）は、サーバーの総メモリの50〜75%に収めます。8GBのプランなら4〜6GB。残りはOSとJava自体が使います。あわせて`-XX:+UseG1GC`を指定します。メモリを増やしたら同じ比率で調整し、再起動して反映します。

接続はJava版クライアントのマルチプレイから「サーバーを追加」でIPかドメインを入れます。DNSのAレコードを`mc.example.com`のような名前で作っておくと、プレイヤーにIPを覚えてもらう手間が消えます。サーバーアイコンは`/home/minecraft/`に64×64ピクセルのPNGを`server-icon.png`という名前で置き、再起動すれば反映されます。screenセッションから抜けるときは`Ctrl + A`の後に`D`で、サーバーは止まりません。

## この構成が向かない人

**スマホやSwitch、プレイステーションの友達と遊びたい人。** VultrのMarketplaceアプリが配備するのはJava版のサーバーで、公式ドキュメントの接続手順もJava版クライアント向けです。ベッドロック版向けの記述はありません。遊ぶ相手が全員Java版を持っているかを先に確認してください。

**2週間だけ、3人以下で遊ぶ人。** 1GBプランは公式に「テスト・小規模」と書かれている構成です。短期の遊びのためにサーバーを立てるより、Realmsなどのマネージドサービスや、友人の誰かにワールドを開いてもらう方が安く済みます。Vultrは時間課金なので20分で削除しても1時間分は課金されますが、それでも数日単位なら誤差です。問題は手間の方で、SSHでufwを開け、`server.properties`を編集する作業を2週間のためにやる価値があるかで判断してください。

**コマンドラインに触りたくない人。** `systemctl`でのサービス管理、`ufw`、`server.properties`の編集、JVMオプションの調整はすべてSSH越しの作業です。Vultrの管理画面にはMinecraft専用の操作パネルはありません。サードパーティ製の管理パネルを上に載せる選択肢もありますが、それは別途構築と費用の話になります。

## よくある質問

**2GBで足りますか。**
バニラを5人前後で遊ぶなら足ります。公式も2GB/2CPUを推奨最低ラインとしています。Paperに変える、プラグインを10個以上入れる、拠点に大量のエンティティを置く、のいずれかに当てはまるなら4GB以上にしてください。

**後からプランを下げられますか。**
下げられません。Change Planでできるのは上位への変更だけです。上げる前提で小さく始めるのが正解です。

**25565を開けたのに接続できません。**
`sudo systemctl status minecraft`でサービスが`active (running)`か、`sudo ufw status`で25565が許可されているか、`server.properties`の`server-ip`が空欄かを順に確認します。起動しない場合はポートの競合、ファイルの権限、サービスのログを見ます。動いているのに重い・落ちる場合は、`-Xmx`の設定、`view-distance`を下げる、crash reportsを読むの3つを試す順番にしてください。

**バックアップはどう取りますか。**
確実なのはサーバーを停止して`world`ディレクトリを圧縮し、終わったら起動する方法です。動かしたまま圧縮すると一貫性が崩れます。自動化するなら停止と圧縮と起動を1本のスクリプトにしてcronに登録します（毎日3時など）。復元は停止、現状の退避、展開、起動の順です。Vultrの自動バックアップは別料金のオプションで、こちらはインスタンス全体を対象にします。

**ホワイトリストはどこで管理しますか。**
`/home/minecraft/whitelist.json`です。プレイヤーの追加はサーバーコンソールから行い、OPの付与・剥奪、BANと解除も同じコンソールで操作します。私的なサーバーなら`white-list=true`と`online-mode=true`を両方設定してください。前者は知らない人の侵入を、後者は改造クライアントを防ぎます。
